# 环境安装

## 1. 必需组件

| 组件 | 版本 | 说明 |
| --- | --- | --- |
| Python | 3.10+ | 3.12 已验证 |
| pymupdf | ≥1.24 | PDF 分页文本 / 内嵌图片 / 矢量区域渲染 |
| Pillow | ≥10 | 自制动画 GIF + 分步静态图 |
| Jinja2 | ≥3.1 | Markdown 模板 |
| rapidfuzz | ≥3.0 | 原文引用模糊比对(门禁核心) |
| jsonschema | ≥4.0 | `note.json` 结构校验 |
| requests | ≥2.31 | 仅在启用 AI 示意图时用到 |

一句话装完:

```bash
pip install -r requirements.txt
```

## 2. Windows(推荐路径)

```powershell
cd <本仓库目录>

# 建虚拟环境
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 装依赖
pip install -r requirements.txt

# 生成配置
python -m nlnotes init
```

然后编辑 `config/pipeline.json`,至少改两项:

```json
{
  "source_root": "D:/NetworkLessons/All-Courses-v3.0",
  "font_path": "C:/Windows/Fonts/msyh.ttc"
}
```

> 路径用正斜杠 `/` 或双反斜杠 `\\`,单反斜杠在 JSON 里是转义符会报错。
> 工具内部会自动把 `\` 统一成 `/`,所以命令行里 `--source-root "D:\NetworkLessons\All-Courses-v3.0"` 也可以。

最后体检:

```powershell
python -m nlnotes doctor
```

期望看到:

```
课程根目录    : D:/NetworkLessons/All-Courses-v3.0  ✅ 存在
必需依赖:
  ✅ pymupdf ... ✅ jsonschema
中文字体      : C:/Windows/Fonts/msyh.ttc
✅ 环境就绪
```

## 3. macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m nlnotes init
```

字体一般能自动探测(macOS 用 PingFang,Linux 用 Noto CJK 或文泉驿)。
探测不到就装一个再在配置里指定:

```bash
# Debian / Ubuntu
sudo apt install fonts-noto-cjk       # 或 fonts-wqy-microhei
```

## 4. 可选组件(缺了会自动降级,不影响出笔记)

| 组件 | 作用 | 缺失时的行为 | 安装 |
| --- | --- | --- | --- |
| **mermaid-cli** | 把 mermaid 图渲染成 PNG | 在 Markdown 里内联 mermaid 代码块(Obsidian/Typora/VS Code/GitHub 都能显示) | `npm i -g @mermaid-js/mermaid-cli` |
| **graphviz** | 把 DOT 图渲染成 PNG | 内联 dot 代码块 | Windows: `winget install graphviz`;mac: `brew install graphviz`;Linux: `apt install graphviz` |
| **ffmpeg** | 在 GIF 之外再出一份 MP4 | 只输出 GIF + 分步静态图 | Windows: `winget install ffmpeg`;mac: `brew install ffmpeg` |
| **tesseract + pytesseract** | OCR 拓扑图里的文字,自动核对 `labels_seen` | 不核对,只在报告里列出登记的标签供人工抽查 | 见下文 |

### 4.1 启用拓扑图 OCR(推荐)

拓扑图里的设备名与网段只存在于图片像素中。开启 OCR 后,这些文字会进入证据库,
门禁就能自动核对 AI 声称"从图上读到"的标签。

```bash
pip install pytesseract

# Windows
winget install UB-Mannheim.TesseractOCR
# macOS
brew install tesseract
# Debian / Ubuntu
sudo apt install tesseract-ocr
```

然后在 `config/pipeline.json` 里:

```json
{ "figure_ocr": true, "ocr_lang": "eng" }
```

开启后需要重新抽取(OCR 结果存在抽取产物里):

```bash
python -m nlnotes extract --force
```

> OCR 只用于**核对**,不会把 OCR 文本当成正文写进笔记。
> Windows 上若报找不到 tesseract,把安装目录加入 PATH,或设置
> `pytesseract.pytesseract.tesseract_cmd`(可在 `nlnotes/extract.py` 的 `_ocr_image` 里指定)。

### 4.2 启用 AI 示意图(可选,谨慎使用)

只在"概念极抽象、必须靠类比"时才需要。前四种可视化(packet_flow / mermaid /
graphviz / 对比表)已经能覆盖绝大多数场景。

**Gemini(即 nano banana 系列图像模型):**

```json
{
  "illustration_provider": "gemini",
  "gemini_model": "gemini-2.5-flash-image"
}
```

```powershell
$env:GEMINI_API_KEY = "你的 key"
```

**OpenAI:**

```json
{ "illustration_provider": "openai", "openai_image_model": "gpt-image-1" }
```

```powershell
$env:OPENAI_API_KEY = "你的 key"
```

行为说明:

- 未设置 Key 时**不报错**,跳过生成、保留提示词,笔记里给出说明。
- 生成的图会自动打上"AI 辅助示意图 · 非 PDF 原图"水印,
  并在笔记附录声明"不属于原文内容"。
- 提示词会被限制:图中只允许出现 `must_include_labels` 里的文字,
  且这些文字必须来自原文。
- 每张图的提示词与原文依据都会存成 `build/visuals/<id>/<vid>-prompt.json`,可审计。
- 模型名会随厂商更新,若报模型不存在,改 `gemini_model` / `openai_image_model` 即可,
  代码不用动。

## 5. 目录约定

```
config/pipeline.json     你的配置(由 init 生成,已被 .gitignore 忽略)
build/                   中间产物,可随时删除重建
notes/                   最终中文笔记(镜像源课程目录树)
glossary/terms.csv       术语中英对照,可自行扩充
prompts/                 给 AI 的提示词
templates/note.md.j2     笔记排版模板,想改样式改这里
schemas/note.schema.json AI 输出结构定义
```

`build/` 与 `notes/` 默认不进版本库。想把笔记纳入 Git,把 `.gitignore` 里的
`notes/` 一行删掉即可(注意 GIF/PNG 会让仓库变大)。
