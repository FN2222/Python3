# 验收与自测

## 一、跑一遍自测

```bash
python tests/run_e2e.py
```

它做四件事:

1. 用 reportlab 造一份"假课程" PDF(4 页、2 张拓扑图、1 段 CLI 输出),
   目录结构模仿真实课程(`IGP/OSPF/xxx.pdf`);
2. 跑完整流水线:`scan → extract → tasks →`(注入示例 `note.json`)`→ verify → visuals → assemble`;
3. 检查产物:Markdown 是否含费曼章节/双语答案/原文图/动画 GIF/分步静态图/
   内联 mermaid/对比表格/逐字 CLI;GIF 与 PNG 是否真的生成;
4. 跑 **14 个臆想反例**,确认门禁每一条都拦得住;
5. 确认源 PDF 的大小与修改时间**未发生变化**。

期望输出末尾:

```
============================================================
✅ 全部自测通过
```

## 二、14 个必须被拦住的反例

| 反例 | 触发的错误码 |
| --- | --- |
| 编造定时器数值(把 40 秒写成 120 秒) | `T001` |
| 编造协议名(`FooBarProtocol`) | `T001` |
| 引用不是原文(自己改写英文句) | `Q001` |
| 页码写错(内容在 p.1 却标 p.3) | `Q001`(并提示正确页码) |
| 引用不存在的图(`fig-p099-1`) | `G001` |
| 发散措辞("笔者认为……生产环境") | `F001` |
| 题目数量不足 | `S001`(schema 的 minItems) |
| 英文答案混入中文 | `X008` |
| 覆盖度不足(只写第一小节) | `X001` + `X011` |
| 自制图依据不是原文 | `V001` |
| 自制图引用未定义节点 | `V012` |
| 配置块被改写 | `C002` + `C003` |
| 结构里出现未定义字段 | `S001` |
| 用了图上标签但没登记 `labels_seen` | `T001` |

这 14 条覆盖了"发散/臆想"的主要形态:编数值、编名词、编原文、编图、
编配置、编结构、少写、超纲。

## 三、门禁完整清单

### S 组 · 结构

| 码 | 检查 |
| --- | --- |
| `S001` | 符合 `note.schema.json`(`additionalProperties: false`,不许加字段) |
| `S002`~`S004` | 小节 id / 可视化 id / 题目 id 唯一 |
| `S005` | `pdf_id` 与任务包一致 |

### P 组 · 页码

| 码 | 检查 |
| --- | --- |
| `P001` | 所有引用页码在 `1 ~ 总页数` 之间 |

### Q 组 · 原文引用

| 码 | 检查 |
| --- | --- |
| `Q001` | 每条 `points[].text_en_quote` 与其声明页的模糊相似度 ≥ `quote_match_threshold`(默认 90);若在别的页命中会直接告知正确页码 |
| `Q002` | 每题 `evidence_quote` 同上 |
| `Q010`(警告) | `heading_en` 在原文中的匹配度 ≥ 80 |

### T 组 · token 依据

| 码 | 检查 |
| --- | --- |
| `T001` | 中文字段里的英文词、IP、≥2 位数字都能在原文找到;`DR/BDR`、`2-Way` 这类组合词会拆开逐段核对;拓扑图标签走 `labels_seen` 通道 |
| `T002` | `terms[].en` 必须在原文出现(短缩写大小写敏感) |
| `T003`(警告) | 译名与 `glossary/terms.csv` 一致 |

### F 组 · 发散措辞

| 码 | 检查 |
| --- | --- |
| `F001` | 不含 `forbidden_phrases` 里的任何一条 |

### G 组 · 图片

| 码 | 检查 |
| --- | --- |
| `G001` `G002` | `figure_id` 真实存在(正文引用 / 题目引用) |
| `G003` | 引用的原文图数 ≥ `可用图数 × min_figure_reference_ratio`(默认 60%) |
| `G010` | `labels_seen` 能在该图的 OCR 结果中找到(仅开启 OCR 时) |
| `G011`(警告) | 未开启 OCR 时,列出所有登记的图内标签供人工抽查 |

### C 组 · 配置

| 码 | 检查 |
| --- | --- |
| `C001` | 配置块页码正确 |
| `C002` | 配置块是原文逐字内容(相似度 ≥ 85) |
| `C003` | 逐行注解引用的行确实在该配置块中 |

### V 组 · 可视化

| 码 | 检查 |
| --- | --- |
| `V001` | 每条 `grounding` 与原文相似度 ≥ `visual_quote_threshold`(默认 88) |
| `V010`~`V013` | `packet_flow` 节点数 ≥2、有 steps、报文与链路只能引用已定义节点 |
| `V014`~`V017` | mermaid / graphviz / 对比表 / AI 图的必填字段完整 |
| `V018`(警告) | AI 示意图超过 1 个 |

### X 组 · 覆盖与测验

| 码 | 检查 |
| --- | --- |
| `X001` | 正文覆盖率 ≥ `coverage_min_ratio`(默认 80%);**只算正文小节,不把测验算进去** |
| `X002` `X003` | 题目数量在 `min_questions ~ max_questions` 之间 |
| `X004` | 覆盖 `required_question_types`(默认 concept + process) |
| `X005`~`X008` | 中文字段含中文、英文字段不含中文 |
| `X009`(警告) | 小节数 ≥ `min_sections` |
| `X010`(警告) | `title_zh` 是中文 |
| `X011` | **题目引用的页必须是正文已讲过的页**(反超纲) |

## 四、人工验收清单(每批抽 1~2 篇)

内容正确性(门禁已覆盖,抽查确认):

- [ ] 随机挑 3 条知识点,回到 PDF 对应页,确认中文没有超出英文原句的信息
- [ ] 随机挑 2 道费曼题,确认答案能在原文找到,且不超纲
- [ ] 确认拓扑图是原文的图,没有被改绘
- [ ] 确认自制图里的节点名、报文名都能在原文或图上找到

可读性(门禁覆盖不到,必须人看):

- [ ] 中文顺畅,没有翻译腔长句
- [ ] 图配在对应知识点旁边,不是堆在文末
- [ ] 自制图确实解决了一个抽象点(看 `why_zh` 是否成立)
- [ ] 费曼题目不是"照抄一句就能答"的水题

源文件安全:

- [ ] `D:\NetworkLessons\All-Courses-v3.0` 下的 PDF 修改时间与大小未变
      (可用 `Get-ChildItem -Recurse -Filter *.pdf | Select-Object Name,Length,LastWriteTime` 比对)

## 五、这套门禁保证什么、不保证什么

**保证:**

- 笔记里的每条结论都能追溯到原文某一页的某一句英文;
- 不会出现原文没有的协议名、命令、数值、IP;
- 不会漏掉大段原文(覆盖率下限);
- 费曼题目不超出正文已讲范围;
- 中英双语字段不会串行;
- 源 PDF 不被修改。

**不保证(需要人工):**

- 中文表达是否优美、是否有翻译腔;
- 小节划分是否符合你的学习习惯;
- 自制图的美观程度与"是不是最好的表达方式";
- 术语译名是否符合你个人偏好(可通过 `glossary/terms.csv` 统一)。
