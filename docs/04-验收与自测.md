# 验收与自测

## 一、跑一遍自测

```bash
python tests/run_e2e.py
```

它做八件事:

1. 用 reportlab 造两份"假课程" PDF:一份正常的(4 页、2 张拓扑图、1 段 CLI 输出),
   一份**扫描件**(整页图片、没有文本层),目录结构模仿真实课程(`IGP/OSPF/xxx.pdf`);
2. 跑准备阶段:`scan → extract → tasks`,检查任务包 9 个文件齐全;
3. 跑 `audit`,确认扫描件被剔除、报告给出 OCR 处理建议、后续阶段自动跳过它;
4. 章节笔记:注入示例 `note.json` → 门禁通过 → 渲染 Markdown,
   检查是否含费曼六步(含**必须掌握清单**与**难点分析**)、双语答案、原文图、
   动画 GIF、分步静态图、内联 mermaid、对比表格、逐字 CLI;
5. 协议级面试复习笔记:`groups` 分组 → 注入 `interview.json` → 门禁通过 →
   渲染 Markdown,检查六个区块、三层追问标签、双语、课程外扩展标注、跨章链接;
6. **AI 自动撰写闭环**:启动一个本地假 LLM 服务,第 1 轮故意返回带臆想的内容
   (编造定时器数值 + 改写原文引用),验证门禁能拦下、错误能回灌、第 2 轮能通过。
   **全程不花一分钱**,也不需要任何 API Key;
7. 跑 **27 个臆想反例**(18 个章节笔记 + 9 个面试笔记),确认门禁每一条都拦得住;
8. 确认源 PDF 的大小与修改时间**未发生变化**,被剔除的 PDF 也原样保留。

期望输出末尾:

```
============================================================
✅ 全部自测通过
```

## 三、门禁完整清单

### S 组 · 结构

| 码 | 检查 |
| --- | --- |
| `S001` | 符合 `note.schema.json`(`additionalProperties: false`,不许加字段) |
| `S002`~`S004` | 小节 id / 可视化 id / 题目 id 唯一 |
| `S005` | `pdf_id` 与任务包一致 |

### P 组 · 页码

| 码 | 检查 |
| --- | --- |
| `P001` | 所有引用页码在 `1 ~ 总页数` 之间 |

### Q 组 · 原文引用

| 码 | 检查 |
| --- | --- |
| `Q001` | 每条 `points[].text_en_quote` 与其声明页的模糊相似度 ≥ `quote_match_threshold`(默认 90);若在别的页命中会直接告知正确页码 |
| `Q002` | 每题 `evidence_quote` 同上 |
| `Q010`(警告) | `heading_en` 在原文中的匹配度 ≥ 80 |

### T 组 · token 依据

| 码 | 检查 |
| --- | --- |
| `T001` | 中文字段里的英文词、IP、≥2 位数字都能在原文找到;`DR/BDR`、`2-Way` 这类组合词会拆开逐段核对;拓扑图标签走 `labels_seen` 通道 |
| `T002` | `terms[].en` 必须在原文出现(短缩写大小写敏感) |
| `T003`(警告) | 译名与 `glossary/terms.csv` 一致 |

### F 组 · 发散措辞

| 码 | 检查 |
| --- | --- |
| `F001` | 不含 `forbidden_phrases` 里的任何一条 |

### G 组 · 图片

| 码 | 检查 |
| --- | --- |
| `G001` `G002` | `figure_id` 真实存在(正文引用 / 题目引用) |
| `G003` | 引用的原文图数 ≥ `可用图数 × min_figure_reference_ratio`(默认 60%) |
| `G010` | `labels_seen` 能在该图的 OCR 结果中找到(仅开启 OCR 时) |
| `G011`(警告) | 未开启 OCR 时,列出所有登记的图内标签供人工抽查 |

### C 组 · 配置

| 码 | 检查 |
| --- | --- |
| `C001` | 配置块页码正确 |
| `C002` | 配置块是原文逐字内容(相似度 ≥ 85) |
| `C003` | 逐行注解引用的行确实在该配置块中 |

### V 组 · 可视化

| 码 | 检查 |
| --- | --- |
| `V001` | 每条 `grounding` 与原文相似度 ≥ `visual_quote_threshold`(默认 88) |
| `V010`~`V013` | `packet_flow` 节点数 ≥2、有 steps、报文与链路只能引用已定义节点 |
| `V014`~`V017` | mermaid / graphviz / 对比表 / AI 图的必填字段完整 |
| `V018`(警告) | AI 示意图超过 1 个 |

### X 组 · 覆盖与测验

| 码 | 检查 |
| --- | --- |
| `X001` | 正文覆盖率 ≥ `coverage_min_ratio`(默认 80%);**只算正文小节,不把测验算进去** |
| `X002` `X003` | 题目数量在 `min_questions ~ max_questions` 之间 |
| `X004` | 覆盖 `required_question_types`(默认 concept + process) |
| `X005`~`X008` | 中文字段含中文、英文字段不含中文 |
| `X009`(警告) | 小节数 ≥ `min_sections` |
| `X010`(警告) | `title_zh` 是中文 |
| `X011` | **费曼引用的页必须是正文已讲过的页**(反超纲,含 must_master / difficulties) |
| `X012` | **知识点密度 ≥ `min_points_per_content_page`**(默认 2.0 条/正文页,反空洞概括) |
| `X013`(警告) | 填了 `detail_zh` 的知识点占比 ≥ 25% |

Q 组另有两条针对费曼新增区块:

| 码 | 检查 |
| --- | --- |
| `Q003` | `must_master[].evidence_quote` 与其声明页比对 |
| `Q004` | `difficulties[].evidence_quote` 与其声明页比对 |

### 协议级面试复习笔记的门禁

| 码 | 检查 |
| --- | --- |
| `S001` `S002` | 符合 `interview.schema.json`(含各区块数量下限、三层追问);id 唯一 |
| `A001`~`A004` | `covered_chapters` 必须属于本分组、且该章已有 note.json;能加载抽取产物 |
| `G001` | 每个条目至少 1 条 `grounding` |
| `G002` `G003` | `grounding.pdf_id` 在覆盖范围内;页码在该章页数范围内 |
| `G004` `G005` | 引用与原文比对(阈值 `interview_quote_threshold`,默认 88);页码错会告知正确页 |
| `T001` | 受约束字段(题干 / 答题模板 / 场景 / 追问答案 / 避坑正误)里的技术词与数字,必须在本组任意一章原文中有依据 —— **课程外内容必须放 `extension_*`** |
| `X001` `X002` | 中英双语纯度 |
| `X003` | 各区块数量下限(must_master / fundamentals / scenarios / followups / pitfalls) |
| `X004` | 连环追问必须正好三层,`level` 依次为 1/2/3 |
| `F001` | 不确定表述(据说 / 我猜 / 大概是 / 不太确定)一律拦下 |

## 四、人工验收清单(每批抽 1~2 篇)

内容正确性(门禁已覆盖,抽查确认):

- [ ] 随机挑 3 条知识点,回到 PDF 对应页,确认中文没有超出英文原句的信息
- [ ] 随机挑 2 道费曼题,确认答案能在原文找到,且不超纲
- [ ] 确认拓扑图是原文的图,没有被改绘
- [ ] 确认自制图里的节点名、报文名都能在原文或图上找到

可读性(门禁覆盖不到,必须人看):

- [ ] 中文顺畅,没有翻译腔长句
- [ ] 图配在对应知识点旁边,不是堆在文末
- [ ] 自制图确实解决了一个抽象点(看 `why_zh` 是否成立)
- [ ] 费曼题目不是"照抄一句就能答"的水题

源文件安全:

- [ ] `D:\NetworkLessons\All-Courses-v3.0` 下的 PDF 修改时间与大小未变
      (可用 `Get-ChildItem -Recurse -Filter *.pdf | Select-Object Name,Length,LastWriteTime` 比对)

## 五、这套门禁保证什么、不保证什么

**保证:**

- 笔记里的每条结论都能追溯到原文某一页的某一句英文;
- 不会出现原文没有的协议名、命令、数值、IP;
- 不会漏掉大段原文(覆盖率下限),也不会只写一层标题式概括(密度下限);
- 费曼的必须掌握与难点都带原文依据,题目不超出正文已讲范围;
- 面试复习笔记的核心答案同样可追溯;课程外内容被强制隔离到独立区块;
- 中英双语字段不会串行;
- 源 PDF 不被修改。

**不保证(需要人工):**

- 中文表达是否优美、是否有翻译腔;
- 小节划分是否符合你的学习习惯;
- 自制图的美观程度与"是不是最好的表达方式";
- 术语译名是否符合你个人偏好(可通过 `glossary/terms.csv` 统一)。
