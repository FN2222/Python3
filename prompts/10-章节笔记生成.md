# 用户提示词模板 —— 生成某一章的 note.json

> 用法:把 `{{...}}` 占位符替换成实际内容后,作为用户消息发给 AI。
> 若你的 AI 工具(Cursor / Claude Code / Codex 等)能直接读文件,
> 可以只发路径,让它自己 `Read`,这样更省 token。

---

请为下面这一章生成 `note.json`。

## 任务包位置

```
{{TASK_DIR}}
```

请先按顺序读完这些文件:

1. `{{TASK_DIR}}/TASK.md` —— 任务要求与门禁阈值(**最重要**)
2. `{{TASK_DIR}}/source-text.md` —— 原文全文,页码标记为 `[[p.N]]`
3. `{{TASK_DIR}}/outline.md` —— 原文标题层级
4. `{{TASK_DIR}}/figures.md` —— 可用图清单;**请逐张打开图片看清楚**
5. `{{TASK_DIR}}/glossary.md` —— 术语统一译名
6. `{{TASK_DIR}}/codeblocks.md` —— 原文配置/命令块
7. `{{TASK_DIR}}/note.schema.json` —— 输出结构
8. `{{TASK_DIR}}/note.template.json` —— 骨架模板

## 本章参数

- pdf_id: `{{PDF_ID}}`
- 源文件: `{{REL_PATH}}`
- 总页数: {{PAGES_TOTAL}};正文页: {{CONTENT_PAGES}}
- 可用图片: {{FIGURE_COUNT}} 张,至少需引用 {{MIN_FIG_REF}} 张
- 覆盖度要求: ≥ {{COVERAGE}}
- 费曼题目: {{MIN_Q}} ~ {{MAX_Q}} 题

## 输出

把结果写到:

```
{{TASK_DIR}}/OUTPUT/note.json
```

写完后立刻运行:

```bash
python -m nlnotes build --id {{PDF_ID}}
```

如果报告里有错误,**逐条修 `note.json` 并重跑,直到通过**。
不要跳过错误,不要修改门禁配置来"绕过"错误。

## 提醒

- 每条 `points[].text_en_quote` 必须是**同一页内连续原文**,不能改写;
  ` ... ` 只省略同一句内部的从句,禁止跨页、禁止拼接不相邻的命令行。
- 中文里出现的每个英文词、每个两位以上的数字,原文里都要有。
  不要自行发明缩写、不要把 `255.255.255.0` 改写成 `/24`、不要在中文里写 `vs`。
- `terms[].en` 用本章原文的实际用词,不要把 `DR` 展开成原文没出现的全称。
- `points[].kind` 不要填 `process`(那是题目的 `type`)。
- `kind` 为 mechanism / step / caveat / definition 的知识点必须有 `detail_zh`;
  密度目标 ≥ 3.0,不要贴着 2.0 门槛停。
- 拓扑图上的设备名/网段要先登记到 `figures[].labels_seen`;讲解里不要写 figure_id。
- 费曼题目不能超纲,每题都要有 `evidence_quote`;`answer_zh` ≥ 25 字,`why_zh` ≥ 15 字。
